# Suporte

- **Dúvidas sobre backend:** abra uma discussion no [fórum](https://github.com/backend-br/forum/discussions).
- **Divulgar uma vaga:** use os formulários do [backend-br/vagas](https://github.com/backend-br/vagas#como-cadastrar-uma-vaga).
- **Divulgar seu perfil:** use o formulário do [backend-br/me-contrata](https://github.com/backend-br/me-contrata#como-se-cadastrar).
- **Problema em um repositório**, como um erro no site ou em um workflow: abra uma issue no repositório correspondente.
- **Comportamento inaceitável:** use a categoria
  [Reportando comportamento inaceitável](https://github.com/backend-br/forum/discussions/categories/reportando-comportamento-inaceit%C3%A1vel)
  do fórum.
- **Vulnerabilidade:** siga a [política de segurança](SECURITY.md).
