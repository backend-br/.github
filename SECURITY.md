# Política de segurança

## Como relatar uma vulnerabilidade

Não abra issue, discussion ou pull request público para relatar uma vulnerabilidade.

Use o relato privado do GitHub: na aba **Security** do repositório afetado, clique em **Report a vulnerability**. Só as
pessoas mantenedoras veem o relato.

Inclua no relato:

- o repositório e o arquivo, workflow ou página afetada;
- os passos para reproduzir;
- o impacto que você espera.

## Escopo

Os repositórios da organização [backend-br](https://github.com/backend-br): workflows do GitHub Actions, scripts de
triagem e o site [backend-br.github.io](https://backend-br.github.io).

Uma vaga, um perfil ou um comentário publicado por outra pessoa não é uma vulnerabilidade. Para isso, use a categoria
[Reportando comportamento inaceitável](https://github.com/backend-br/forum/discussions/categories/reportando-comportamento-inaceit%C3%A1vel)
do fórum.
