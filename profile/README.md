# Back-End Brasil

Comunidade brasileira de pessoas desenvolvedoras backend, em qualquer nível de conhecimento. Vagas, perfis, desafios e
discussões ficam em aberto, nos repositórios abaixo.

| Repositório | Para quê |
| --- | --- |
| [vagas](https://github.com/backend-br/vagas) | Divulgação de vagas para pessoas desenvolvedoras backend, via issues do GitHub. |
| [me-contrata](https://github.com/backend-br/me-contrata) | Perfis de pessoas em busca de emprego na área de TI. |
| [desafios](https://github.com/backend-br/desafios) | Desafios para aprimorar habilidades de programação com foco em backend. |
| [opensource-br](https://github.com/backend-br/opensource-br) | Divulgação de projetos open source brasileiros. |
| [forum](https://github.com/backend-br/forum) | Dúvidas, sugestões e discussões sobre backend. |
| [como-instalar-xyz](https://github.com/backend-br/como-instalar-xyz) | Tutoriais de instalação para pessoas desenvolvedoras. |
| [eventos](https://github.com/backend-br/eventos) | Eventos, meetups e encontros de backend. |
| [poste-mais](https://github.com/backend-br/poste-mais) | Divulgação de artigos brasileiros sobre desenvolvimento backend. |

No [site](https://backend-br.github.io) ficam as [vagas](https://backend-br.github.io/vagas/), os
[talentos](https://backend-br.github.io/talentos/), os [desafios](https://backend-br.github.io/desafios/) e os
[projetos](https://backend-br.github.io/projetos/). As vagas também saem em
[RSS](https://backend-br.github.io/vagas.xml) e em [JSON](https://backend-br.github.io/vagas.json).
